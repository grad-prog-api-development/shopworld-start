## Console app
- Creëer modellen voor je Http calls in een aparte class library
- Maak een http requests
    - Gebruik de httpclient library
    - Lees het antwoord eerst uit als tekst
    - Vorm deze om naar het gepaste model

## WPF-applicatie
Je krijgt de opdracht om een WPF-applicatie te maken voor een webshop genaamd ShopWorld. De data worden je ter beschikking gesteld via API op volgende [url](https://dummyjson.com/docs/products).

De webshop bestaat uit een overzicht van de producten (Id, titel en prijs). Als je op een product klikt, opent zich een product detail pagina met dezelfde informatie + een afbeelding. De xaml is in beide gevallen reeds gegeven.
